> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix two HIGH-severity security findings: stop PII from being logged/stored unredacted (HIGH-04), and prevent prompt injection via learned patterns (HIGH-05).

**Architecture:** HIGH-04 has three independent fixes — remove a log line, add ingestion-time redaction to `EmailService`, and add a startup validator to `Settings`. HIGH-05 has two fixes — add a character allowlist to `pattern_value` in the Pydantic schema, and change `format_for_prompt()` to emit JSON instead of free-form text. All changes are targeted; no new files are created.

**Tech Stack:** Python, FastAPI, Pydantic v2, pytest-asyncio, `cryptography.fernet` (test fixture only)

```python
def format_for_prompt(self) -> str:
    """Format learned patterns as a JSON block for LLM prompt injection.

    JSON encoding ensures pattern values cannot escape their data context
    and inject instructions into the prompt.
    """
    data: dict[str, list[str]] = {}
    if self.important_domains:
        data["important_domains"] = self.important_domains
    if self.important_keywords:
        data["important_keywords"] = self.important_keywords
    if self.not_important_domains:
        data["not_important_domains"] = self.not_important_domains
    if self.not_important_keywords:
        data["not_important_keywords"] = self.not_important_keywords

    if not data:
        return ""

    return "\n\nLearned Patterns:\n" + json.dumps(data)
```
